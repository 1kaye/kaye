# AGENTS.md

Technical guide and architecture rules for agents and contributors working in the **Kaye OS** repository.

## 1. Architecture Overview

Kaye OS splits responsibilities cleanly across three layers:

1. **Quickshell (`shell/` — thin QML UI)**
   - Single process (`kaye-shell.service`) rendering Background, Startup Intro, Bar, Menu Manager (`Super + Space`), App Launcher, Keybindings Viewer, Notifications, OSD, and Lock Screen.
   - Keep UI modules thin and declarative. Do not write heavy parsing, indexing, or fuzzy-search logic in `.js` files — delegate to the `kaye` Rust binary (`--json`).
2. **Rust Core (`core/` → `~/.local/bin/kaye`)**
   - `core/src/main.rs`: `clap` CLI router.
   - `core/src/theme.rs`: `colors.toml` parser, `.tpl` renderer (`{{ key }}`, `{{ key_strip }}`, `{{ key_rgb }}`), and atomic swap to `~/.local/state/kaye/current/theme/`.
   - `core/src/menu.rs`: JSONC parser (comments + trailing commas), `default/kaye/menu.jsonc` + `~/.config/kaye/menu.jsonc` merger, dotted-ID hierarchy resolver, `.desktop` scanner, fuzzy search, and sandboxed `lua -E` keybindings evaluator (with pure-Rust Lua fallback) over `default/hypr/bindings.lua` + `~/.config/hypr/bindings.lua`.
   - `core/src/config.rs`: Type-safe read/write of `~/.config/kaye/shell.json` (preserving unknown user fields) and `~/.local/state/kaye/toggles/*`.
   - `core/src/system.rs`: Safe subprocess wrappers (`Command::new`) for Snapper, `paccache`, `pacman`/`yay`, `systemctl --user`, and `kaye about`.
3. **Installers & Live ISO (`boot.sh`, `arch-install.sh`, `install/`, `iso/` — Bash)**
   - Strictly limited to idempotent, chroot-safe system provisioning, live-ISO installation, and Archiso image building.

### 3-Layer Configuration Separation

- **Repository defaults (`$KAYE_PATH/`):** `arch-install.sh`, `boot.sh`, `branding/`, `config/`, `core/`, `default/`, `install/`, `iso/`, `plymouth/kaye/`, `shell/`, `themes/`.
- **User overrides (`~/.config/`):** `hypr/*.lua` (+ `.luarc.json`), `kaye/shell.json`, `kaye/menu.jsonc`, `kaye/themes/`, `uwsm/env.d/10-kaye.conf`, `foot/foot.ini`, `fastfetch/config.jsonc`, `gtk-3.0/`, `gtk-4.0/`, `qt6ct/`, `xdg-desktop-portal/`, `mimeapps.list`, `autostart/kaye-first-run.desktop`, `systemd/user/kaye-shell.service`.
- **Runtime state (`~/.local/state/kaye/`):** `current/theme/` (including rendered `hyprland.lua`), `current/theme.name`, `current/background`, `toggles/*`, `default-browser`, `first-run.done`, `install.log`. Never commit runtime state, build artifacts (`core/target/`), or ISO outputs (`iso/out/`, `iso/work/`).

### Branding Surfaces

- Boot splash: `plymouth/kaye/` (`kaye.plymouth`, `kaye.script`, PNG assets).
- Login cover: `shell/modules/intro/StartupIntro.qml` (runs once per Hyprland session via `/tmp/kaye-intro-<sig>.done`).
- Lock screen: `shell/modules/lock/LockScreen.qml` (`WlSessionLock` + `PamContext`).
- CLI / terminal: `branding/logo.txt` used by `kaye about`, `install/lib/ui.sh`, `arch-install.sh`, and `fastfetch`.

## 2. Quickshell & QML Rules

1. **Avoid QtQuick `Color` shadowing:** Always import `import qs.Commons as Commons` and reference `Commons.Color.*`. Never hardcode theme hex colors in UI modules; use `Commons.Color.*` and `Style.*`.
2. **Never stack `HoverHandler` over `MouseArea`:** In Qt 6, an overlaid `HoverHandler` interferes with `MouseArea.onEntered` and breaks bar tooltips.
3. **Tooltip window resolution & fractional scaling:**
   - Match tooltip targets by traversing `item.parent` up to `barWindow.contentItem` (`targetBelongsToWindow()`) rather than relying solely on `target.QsWindow.window`.
   - Keep a short fallback `Timer` (`~120ms`) on tooltip `PopupWindow` so tooltips never stall at zero opacity under fractional scaling.
   - Every bar widget must define `tooltipText`. Calling `showTooltip(target, "")` must not dismiss an active tooltip owned by a different target.
4. **Prevent rich-text injection:** Set `textFormat: Text.PlainText` on all `Text` items rendering dynamic strings (app names, notifications, window titles, CLI output).
5. **Verification:**
   ```bash
   /usr/lib/qt6/bin/qmllint shell/shell.qml shell/Commons/*.qml shell/Ui/*.qml shell/modules/*/*.qml
   journalctl --user -u kaye-shell.service --since "1 minute ago" --no-pager
   ```
   Changes must pass with zero syntax errors, zero `TypeError`, and zero `ReferenceError`.

## 3. Rust (`core/`) Rules

1. Keep dependencies lean (`clap`, `serde`, `serde_json`, `toml`, `anyhow`) to maintain fast builds and sub-15 ms startup latency.
2. Any `--json` subcommand must emit pure JSON to `stdout` (no ANSI escape sequences or extra logs); report errors to `stderr` with a non-zero exit code.
3. Build external process invocations with `Command::new(...).arg(...)` — never interpolate untrusted strings into a shell command.
4. Preserve backward compatibility with user-defined keys in `~/.config/kaye/shell.json`.
5. **Verification:**
   ```bash
   cd core
   cargo fmt --check
   cargo clippy --all-targets -- -D warnings
   cargo test
   cargo build --release
   ```

## 4. Hyprland (0.57+ Lua-Only) & Theme Rules

1. **Lua-only configuration:** Arch `extra/hyprland` 0.57+ dropped legacy `.conf` (Hyprlang) support completely (`CONFIG_LUA` only). Never add `.conf` Hyprland configs or legacy options (`dwindle:pseudotile`, `misc:vfr`, `windowrulev2`, hyphenated input keys).
2. **Module loading flow:** `~/.config/hypr/hyprland.lua` (never set `autogenerated = true`) resolves `KAYE_PATH` (with patched `default_kaye_path` fallback), runs `default/hypr/bootstrap.lua` (sets `package.path` without duplication and resets cached Kaye modules on reload), requires `default/hypr/kaye.lua` (`helpers`, `env`, `input`, `looknfeel`, `bindings`, `windows`, `autostart`, and optional rendered theme `kaye.current.theme.hyprland`), and finally loads optional user overrides (`hypr.{monitors,input,bindings,looknfeel,autostart}`).
3. **Keybindings & launchers:**
   - Always declare bindings via `kaye.bind(keys, description, dispatcher, opts)` (and `kaye.rebind(...)` / `hl.unbind(...)` for overrides) so `kaye menu keybindings` (`Super + K`) discovers descriptions accurately.
   - Launch desktop apps via `kaye.launch(cmd)` so they automatically use `uwsm-app --` inside UWSM sessions and direct execution outside UWSM. Use `kaye.ipc(...)` for Quickshell IPC calls.
4. **Hyprland verification:**
   - Offline / isolated validation: `Hyprland --verify-config` must exit `0` (`config ok`) with zero `autogenerated` warnings (test in an isolated temporary `HOME`/`XDG_CONFIG_HOME`/`XDG_STATE_HOME` before and after theme rendering).
   - Live session validation: `hyprctl reload && hyprctl configerrors` (output must be empty).
5. **Theme templates (`default/themed/*.tpl`):**
   - Includes `hyprland.lua.tpl`, `shell.toml.tpl`, `foot.ini.tpl`, `btop.theme.tpl`, and `neovim.lua.tpl`.
   - Every placeholder must correspond to a key in `colors.toml` (`{{ key }}`, `{{ key_strip }}`, `{{ key_rgb }}`). Verify rendered outputs in `~/.local/state/kaye/current/theme/` contain zero unresolved `{{` tokens across all bundled themes.

## 5. Installer & Archiso Rules

1. **Shell script standards:** Every script in `boot.sh`, `arch-install.sh`, `install/*.sh`, `install/lib/*.sh`, and `iso/*.sh` (plus `iso/overlay/airootfs/usr/local/bin/kaye-iso-installer`) must start with `#!/usr/bin/env bash` and `set -euo pipefail`, be idempotent, keep executable permissions (`chmod +x`), and pass `bash -n`. Validate `config/uwsm/env.d/10-kaye.conf` with `sh -n` and `iso/overlay/airootfs/root/.zlogin` with `bash -n`.
2. **Canonical env contract (`arch-install.sh` → `install/all.sh`):**
   - Keep `KAYE_CHROOT`, `KAYE_NONINTERACTIVE`, `KAYE_THEME` (`catppuccin|tokyo-night|gruvbox`), `KAYE_BROWSER` (`firefox|chromium|skip`), `KAYE_AUTOLOGIN` (`1|0|auto`), and `KAYE_LOG_FILE` strictly aligned across Track 1 and Track 2.
3. **Chroot safety (`KAYE_CHROOT=1`):**
   - Every step in `install/01..08` must run cleanly inside `arch-chroot` as well as on a live Arch host.
   - Never invoke `systemctl enable --now`, `systemctl start`, live `systemctl --user`, live `ufw enable` (write `ENABLED=yes` in `/etc/ufw/ufw.conf` inside chroot), or live D-Bus tools (`gsettings`, `xdg-settings`, `snapper` without `--no-dbus`) when `KAYE_CHROOT=1`.
   - Enable `kaye-shell.service` via a chroot-safe symlink under `~/.config/systemd/user/graphical-session.target.wants/`, and defer live graphical-session actions (`gsettings`, `xdg-settings`, PipeWire/Quickshell start, welcome toast) to `install/first-run.sh` (`~/.local/bin/kaye-first-run`).
   - Always preserve genuine user edits to `~/.config/hypr/hyprland.lua`, while backing up and replacing upstream autogenerated `hyprland.lua` / obsolete `hyprland.conf`.
   - Keep `install/04-boot-and-plymouth.sh` (`KAYE_BOOT_LIB_ONLY=1`), `install/06-core-and-dotfiles.sh` (`KAYE_DOTFILES_LIB_ONLY=1`), and `arch-install.sh --dry-run` testable in isolated temp environments without mutating the host.
4. **Minimal footprint:** Keep `install/packages.base`, `install/packages.aur`, and `iso/packages.x86_64` lean — do not add packages without an explicit requirement.
5. **No machine-specific leakage:** Never hardcode personal usernames, hostnames, mount paths, monitor IDs, timezones, or secrets anywhere in repository files.
